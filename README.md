# 🥋 Jiu-Jitsu Manager

Sistema completo de gerenciamento de aulas de Jiu-Jitsu gratuito, com controle de presença, alunos e faixas.

## 🎯 Funcionalidades

- ✅ Registro de alunos (Adulto e Kids)
- ✅ Controle de presença com status (Presente, Atrasado, Ausente)
- ✅ Gerenciamento de faixas (Branca, Azul, Roxa, Marrom, Preta)
- ✅ Relatório de frequência
- ✅ Gerenciamento de turmas
- ✅ Autenticação de professores via email
- ✅ Dashboard responsivo

## 🛠️ Tecnologias

- **React 18** - Frontend
- **Firebase** - Autenticação, Firestore, Hosting
- **CSS3** - Estilização

## 📋 Pré-requisitos

- Node.js 14+
- npm ou yarn
- Conta Firebase
